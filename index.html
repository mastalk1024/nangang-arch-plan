南港高工建築科 · 三年生涯規劃儀表板

以「升學前三大科大／頂尖建築系」為主軸，串接全球通用的英文、繪圖／BIM 與建築專業證照，並確保每一步都能與現在的建築產業實務銜接。

起點：建築科 高一 英文起點：會考 A～A+（約 CEFR B1） 目標：台科大／北科大建築系 · 國外備援 主訴求：可落實 · 產業可銜接

規劃總覽

這份規劃把三年拆成三條並行的主軸同時推進：升學競爭力、國際通用證照、產業實作能力。三者互相加分——證照與作品集既是統測甄選備審的亮點，也是國外申請作品集與未來就業的底子。

三大主軸怎麼互相加分

主軸一

升學競爭力

主力走 統測（土木與建築群／設計群）→ 四技二專甄選入學，鎖定台科大、北科大、雲科大建築系；同時保留學測 / 特殊選才通往成大、淡江、東海等一般大學建築系的機會。

主軸二

全球通用證照

英文走 TOEIC → IELTS/TOEFL；繪圖走 Autodesk 國際認證（Revit / AutoCAD）＋ SketchUp；專業走 建築製圖技術士（丙→乙）。國際證照是國內外通吃的硬實力。

主軸三

產業可銜接

學校已導入 Revit、SketchUp 等 BIM 教學與 3D 專題。以「一份會成長的作品集」貫穿三年，讓建模、製圖、設計思考直接對應建築師事務所、營造與室內設計的實務需求。

一頁看懂三年節奏

高一 · 打底

基本功＋方向

把手繪、CAD、建模與基礎英文練扎實；先拿下最容易入手的技術士與 Autodesk 入門證照，建立信心與作品集雛形。

高二 · 進階

拉開差距

衝 TOEIC 高分、考進階證照、參加全國競賽與專題；確定升學主戰場（國內為主／國外為輔），開始整理正式作品集。

高三 · 收成

轉換成錄取

統測衝刺與甄選備審全力產出；若走國外，完成 IELTS 與申請作品集、面試與獎學金投遞。

高一 上學期

Autodesk Certified User（ACU）好入手

繪圖 / BIM · 國際證照

官方就是設計給中學生／初學者的入門認證，50 分鐘，AutoCAD 或 Revit 擇一。第一張先拿它，建立信心與國際證照起手式。

2
高一 下學期

丙級 建築製圖應用（手繪 或 電繪）好入手

建築專業技術士 · 國內

南港校內就是甲乙丙級檢定場、輔導通過率高，是最該優先拿下的專業證照。先考手繪或電繪其中一種。

3
高一 暑假

TOEIC 多益（先測基準）中等

英文檢定 · 職場/國內

先考一次抓自己的起點分數（目標實測 ≥ 600），之後才知道要補多少。你會考 A～A+，起點本來就不錯。

4
高二 上學期

丙級 測量好入手

建築專業技術士 · 國內

直接對應統測專業二「測量實習」，考證＝同時練統測，一舉兩得。

5
高二 全年

TOEIC 多益（衝高分）中等

英文檢定 · 職場/國內

主力英檢，目標 750 → 850+。這是甄選備審與科大的實用加分，也是你相對別人的最大優勢。

6
高二 下學期

乙級 建築製圖應用較難

建築專業技術士 · 國內

含金量更高，是技優入學的重要門票、甄選備審的強力加分。校內即可檢定。

7
高二暑假 ～ 高三

Autodesk Certified Professional — Revit 建築較難

繪圖 / BIM · 國際證照

120 分鐘的進階認證，證明 BIM 建模與圖說能力，直接對接業界 Revit 工作流。（可另補 AutoCAD Professional。）

8
高三（走國外才需要）

IELTS 雅思 6.0–6.5較難

英文檢定 · 留學

要申請國外建築系才需要（名校 6.5+）。美國/日本英語學程也可改考 TOEFL 80–100。只走國內就可略過。

＋
彈性 · 選配

SketchUp / Adobe Certified中等

繪圖 / 視覺 · 國際證照

SketchUp 快速方案發想、Adobe（Photoshop/Illustrator/InDesign）做作品集排版與圖面後製。時間有餘、或走國外者可加，讓作品集更完整。

＋
彈性 · 畢業後 / 大學再考

建築物室內裝修（施工 / 設計）中等

建築專業技術士 · 進階

對室內設計有興趣的延伸選項；部分項別需實務經驗，適合畢業後或大學階段再考，不必擠進高中三年。

一句話記住順序：高一先拿「最好入手」的 ①ACU＋②丙級製圖 建立信心 → 高二補 ④測量、衝 ⑤多益、挑戰 ⑥乙級製圖 → 高二暑假起攻 ⑦Revit 專業認證 → 只有走國外才要在高三加考 ⑧IELTS。①〜⑦ 是每個人都建議走的主線，⑧ 與「＋選配」看方向再決定。

國內升學：前三大科大 × 頂尖建築系

建築科主力管道是統測 → 四技二專甄選入學，鎖定台科大、北科大、雲科大建築系；並保留學測 / 特殊選才通往一般大學頂尖建築系的機會。多管道並進＝多重保險。

統測要考什麼？（土木與建築群）

共同科目

國文、英文、數學（英文正是你的相對優勢，會考 A～A+ 可轉成領先）。

專業科目

專業一：基礎工程力學、材料與試驗

專業二：測量實習、製圖實習

＊部分建築系另收「設計群」（考設計概論＋術科）——若設計性向強，高二可評估雙軌。

多元管道（越早準備越有利）

甄選入學

統測成績一階篩選 → 二階備審＋面試。作品集、證照、競賽決勝負。

技優入學

憑全國技藝競賽名次或乙級以上證照保送 / 甄審，證照與競賽是關鍵。

繁星計畫

看在校成績。把高一高二每學期成績顧好就是門票。

聯合登記分發

純看統測分數的最後一關，衝刺分數的保底。

一般大學建築系（第二軌）：成大、淡江、東海、陽明交大等頂尖建築系主要收學測生。若想保留這條路，需高三另備學測，或走特殊選才（以作品集、競賽、專長申請，正好對應你的證照與作品集）。建議高二定案是否雙軌。

國外建築系：推薦 · 面試 · 獎學金

國外採「作品集 + 語言 + 推薦信 + 面試」的申請制，正好把三年累積的證照與作品集直接變現。台灣高職生通常需要一年銜接 / 預科（Foundation）再進大學部。以下為主要選項與資源。

面試與作品集怎麼準備

作品集 Portfolio

10–20 頁，展現設計思考過程而非只有成品：草圖、發想、手繪、模型、Revit/SketchUp 建模、後製排版。三年的專題與競賽作品就是素材庫。

面試 Interview

多為線上，考英文表達＋對作品的說明。用你的英文優勢，練習用英文講三件代表作的概念與取捨。

文書 & 推薦信

Personal Statement 講清楚「為什麼是建築、為什麼是這所學校」；請專業科老師 / 導師寫推薦信，及早溝通。

獎學金與補助資源

教育部管道

• 藝術與設計菁英海外培訓計畫（SPOSAD）：設計相關領域的全額海外培訓補助。

• 教育部公費留學、學海系列（大學階段海外實習 / 交換補助）。

實際資格與名額以各年度簡章為準。

校方 / 民間管道

• 各國大學提供的 International Student Scholarship / Merit Award（憑成績與作品集）。

• 民間企業與基金會留學獎學金。

越強的作品集與語言成績，越容易拿到 merit-based 減免。

💡 國外路線建議定位為「高機會就走、沒到位也不影響國內錄取」的備援選項：把國內統測與甄選顧好當主力，國外用同一套作品集與 IELTS 加碼申請，風險最低、報酬最高。

產業銜接：學的每一步都對得上業界

建築產業正全面走向 BIM 協作。學校已導入 Revit、SketchUp 與 3D 專題，這份規劃刻意讓「證照＝業界工具」「作品集＝實務作品」，畢業即具備可用技能。

往上延伸的專業資格（大學之後的地圖）

建築師

大學建築系畢業 → 實務經驗 → 建築師高考。三年的製圖與設計底子是起點。

土木 / 結構技師

走工程實作路線者的國家考試方向，與力學、材料基礎相接。

BIM / 國際專業

Autodesk 專業認證可一路升級，對應國內外 BIM 職缺與國際事務所。

核心心法：每學期都問一句——「這學到的東西，事務所 / 營造廠會怎麼用？」讓證照不是為考而考，而是把作品集養成一份「能直接拿去面試實習」的實力證明。

軟體工具箱 · 三年會用到的軟體

建築科三年主要用到的五套軟體，附官網、教育版／免費取得方式與教學影片。學生善用「教育版」幾乎都能合法免費或大幅折扣使用；學校電腦教室通常已安裝這些軟體。

🔗 Autodesk 教育總覽

教育版怎麼拿：Autodesk 走「Autodesk Education」以學生身分註冊（通常需就讀證明，一年可續），AutoCAD、Revit、Civil 3D 等一次到位；SketchUp 中學用免費校園版；Twinmotion 直接下載免費版；Adobe 走學生折扣或學校授權。Mac 相容性：AutoCAD、SketchUp、Twinmotion、Adobe 都有 Mac 版；只有 Revit 僅 Windows，用 Parallels 跑 Windows 或直接用學校電腦即可。
⚠️ 教育授權僅供學習用途、不得商用；申請與資格條件、是否免費／折扣以各官網最新公告為準。下載請一律從上方官方連結，避免來路不明的破解版（有資安與法律風險）。
